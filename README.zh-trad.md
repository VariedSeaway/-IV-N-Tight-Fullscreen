# IV-N Tight Fullscreen

[English](README.md) | [中文](README.ZH.md) | [繁体中文](README.zh-trad.md) | [日本语](README.ja.md)

為 DMM 版《イヴンタイト》加上全螢幕功能的 Tampermonkey 腳本。

## 功能

- 一鍵全螢幕，畫面自動維持 16:9 等比縮放並置中
- 黑色背景，隱藏公告與裝飾背景

## 安裝

1. 安裝 [Tampermonkey](https://www.tampermonkey.net/) 瀏覽器擴充功能
2. 開啟本專案的 `.user.js` 檔案，點選 Raw，Tampermonkey 會跳出安裝畫面
3. 按下「安裝」即可

## 使用方式

1. 進入遊戲頁面，右上角會出現紫色「⛶ 全螢幕」按鈕
2. 點擊按鈕進入全螢幕
3. 按 **ESC** 退出全螢幕（全螢幕時按鈕不會顯示）

## 注意事項

- 本腳本只修改畫面樣式，不讀取或傳送任何帳號、遊戲資料，也沒有任何外部連線。
- 這是非官方工具，與 DMM 及遊戲營運方無關，使用風險請自行承擔。
- 若遊戲或 DMM 頁面改版，腳本可能失效。

# IV-N Tight Fullscreen

[English](README.md) | [中文](README.ZH.md) | [繁体中文](README.zh-trad.md) | [日本语](README.ja.md)

为 DMM 版《イヴンタイト》加上全屏幕功能的 Tampermonkey 脚本。

## 功能

- 一键全屏幕，画面自动维持 16:9 等比缩放并置中
- 黑色背景，隐藏公告与装饰背景

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩充功能
2. 开启本专案的 `.user.js` 档案，点选 Raw，Tampermonkey 会跳出安装画面
3. 按下「安装」即可

## 使用方式

1. 进入游戏页面，右上角会出现紫色「⛶ 全屏幕」按钮
2. 点击按钮进入全屏幕
3. 按 **ESC** 退出全屏幕（全屏幕时按钮不会显示）

## 注意事项

- 本脚本只修改画面样式，不读取或传送任何账号、游戏数据，也没有任何外部联机。
- 这是非官方工具，与 DMM 及游戏营运方无关，使用风险请自行承担。
- 若游戏或 DMM 页面改版，脚本可能失效。

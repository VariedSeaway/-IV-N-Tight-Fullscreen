# IV-N Tight Fullscreen

[English](README.md) | [中文](README.ZH.md) | [繁体中文](README.zh-trad.md) | [日本语](README.ja.md)

DMM版『イヴンタイト』にフルスクリーン機能を追加する Tampermonkey 用ユーザースクリプトです。

## 機能

- ワンクリックでフルスクリーン表示。16:9 の比率を保ったまま自動で拡大縮小し、中央に配置します
- 背景を黒にし、お知らせや装飾背景を非表示にします

## インストール

1. ブラウザ拡張機能の [Tampermonkey](https://www.tampermonkey.net/) をインストールします
2. このリポジトリの `.user.js` ファイルを開き、「Raw」をクリックすると、Tampermonkey のインストール画面が表示されます
3. 「インストール」をクリックします

## 使い方

1. ゲームページを開くと、右上に紫色の「⛶ 全螢幕」ボタンが表示されます
2. ボタンをクリックするとフルスクリーンになります
3. **ESC** キーで解除します（フルスクリーン中はボタンは表示されません）

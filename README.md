# IV-N Tight Fullscreen

English | [繁體中文](README.zh-trad.md) | [日本語](README.ja.md)

A Tampermonkey userscript that adds fullscreen mode to the DMM version of "IV-N Tight".

## Features

- One-click fullscreen with automatic 16:9 scaling, centered on screen
- Black background; news and decorative backgrounds are hidden

## Installation

1. Install the [Tampermonkey](https://www.tampermonkey.net/) browser extension.
2. Open the `.user.js` file in this repository and click Raw. Tampermonkey will show an install page.
3. Click "Install".

## Usage

1. Open the game page. A purple "⛶ 全螢幕" button appears at the top right.
2. Click it to enter fullscreen.
3. Press **ESC** to exit. The button is hidden while in fullscreen.

## Notes

- This script only changes page styling. It does not read or send any account or game data, and makes no external requests.
- This is an unofficial tool, not affiliated with DMM or the game's operator. Use at your own risk.
- The script may stop working if DMM or the game updates its page structure.
